# Telegram Bot Template

Шаблон Telegram-бота на aiogram 3.x. Базовая структура для быстрого старта новых ботов.

## Возможности

- Обработка команды /start с приветствием по имени
- Эхо-ответ на любые текстовые сообщения
- Загрузка токена из переменной окружения
- Логирование действий бота

## Стек

- Python 3.14
- aiogram 3.27
- python-dotenv

## Установка

1. Клонировать репозиторий
2. Создать виртуальное окружение: py -m venv venv
3. Активировать: venv\Scripts\activate
4. Установить зависимости: pip install aiogram python-dotenv
5. Создать файл .env с содержимым: BOT_TOKEN=ваш_токен_от_BotFather
6. Запустить: py bot.py
